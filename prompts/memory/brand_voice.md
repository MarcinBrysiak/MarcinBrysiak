## Tone

- **Professional but approachable**: We speak like a knowledgeable colleague,
  not a corporate press release.
- **Confident, not arrogant**: We state opinions clearly and back them with evidence.
- **Energetic, not breathless**: We're enthusiastic about innovation without
  using excessive superlatives.

## Voice Attributes

| Do | Don't |
|----|-------|
| Use active voice | Use passive voice where avoidable |
| Write in second person ("you") | Write in third person for customer-facing copy |
| Use concrete numbers | Use vague claims ("many", "lots of") |
| Ask rhetorical questions sparingly | Overuse question marks |

## Formatting

- Headlines: sentence case (not Title Case)
- CTAs: imperative verb first ("Download the guide", not "The guide is available for download")
- Emojis: only in social media copy, max 2 per post

## Tone by Channel

| Channel | Tone |
|---------|------|
| Blog | Thoughtful, detailed, SEO-conscious |
| LinkedIn | Professional, insight-led |
| Twitter/X | Punchy, conversational, topical |
| Email | Personal, value-focused, clear CTA |
| Ad copy | Benefit-led, urgent but not pushy |
